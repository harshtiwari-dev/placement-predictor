# Experiments Log

## Objective

Evaluate multiple machine learning algorithms for student placement prediction,
compare their performance, analyze explainability using SHAP, and select the most
appropriate model for deployment.

---

# Experiment 1 — Initial Dataset (MBA Placement)

## Dataset

- Source: Kaggle — "Factors Affecting Campus Placement" (benroshan)
- 215 records
- Train/Test Split: 80/20 (`random_state=42`)
- Removed:
  - `sl_no` (identifier)
  - `salary` (data leakage)
- One-hot encoding applied to categorical features

## Model Comparison

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.884 | 0.91 | 0.94 | 0.92 | 0.930 |
| Random Forest | 0.814 | 0.83 | 0.94 | 0.88 | 0.849 |
| XGBoost | 0.837 | 0.85 | 0.94 | 0.89 | 0.874 |

### SHAP Analysis

Global feature importance showed:

1. SSC Percentage
2. Degree Percentage
3. MBA Percentage
4. HSC Percentage
5. Work Experience

### Observation

Although Logistic Regression performed best, this dataset represents MBA students
rather than engineering students and therefore was not suitable for the project's
target audience.

Decision:
Dataset rejected.

# Experiment 2 — College Student Placement Factors Dataset

## Dataset

- Source: Kaggle — "College Student Placement Factors"
- 10,000 records
- Features included:
  - IQ
  - CGPA
  - Communication Skills
  - Internship Experience
  - Projects
  - Academic Performance
  - Extra Curricular Score

Class Distribution

- Placed: 1,659
- Not Placed: 8,341

Strong class imbalance (16.6% placement rate).

## Model Comparison

| Model | Accuracy | ROC-AUC |
|---|---:|---:|
| Logistic Regression | 0.904 | 0.944 |
| Random Forest | 1.000 | 1.000 |
| XGBoost | 1.000 | 1.000 |

### Additional Experiment

Balanced versions of all models were tested using
`class_weight="balanced"`.

Result:

- Logistic Regression improved minority recall but reduced overall accuracy.
- Random Forest and XGBoost still achieved perfect scores.

### Observation

Perfect accuracy strongly suggested the dataset labels were generated by a
deterministic rule rather than genuine student outcomes.

Although Logistic Regression behaved realistically, the severe class imbalance
produced unintuitive prediction probabilities for average students.

Decision:

Dataset rejected.

# Experiment 3 — Final Dataset (Selected)

## Dataset

Source:

Kaggle — "Placement Prediction Dataset" (ruchikakumbhar)

Dataset Size

- 10,000 students

Class Distribution

- Not Placed: 5,803
- Placed: 4,197

Features

- CGPA
- Internships
- Projects
- Workshops/Certifications
- Aptitude Test Score
- Soft Skills Rating
- Extracurricular Activities
- Placement Training
- SSC Marks
- HSC Marks

Dataset Verification

- No missing values
- No duplicate rows
- No suspicious feature leakage
- Feature correlations between 0.26–0.52

---

## Model Comparison

| Model | Accuracy | ROC-AUC |
|---|---:|---:|
| Logistic Regression | **0.7945** | **0.877** |
| Logistic Regression (Balanced) | 0.7905 | 0.877 |
| Random Forest | 0.7815 | 0.867 |
| XGBoost | 0.7785 | 0.858 |

### Observation

Unlike previous datasets,

- no model achieved suspiciously perfect performance,
- balancing produced almost no improvement,
- Logistic Regression achieved the best overall metrics.

Decision:

**Logistic Regression selected as the production model.**

---

# Probability Validation

The deployed model was validated using probability outputs rather than only binary
classification.

Observed behaviour:

- Weak profiles received low placement probabilities.
- Strong profiles received high placement probabilities.
- Average profiles produced moderate probabilities consistent with the dataset.

To provide additional context for users, each prediction is also compared against
the distribution of training-set probabilities to calculate a percentile ranking.
